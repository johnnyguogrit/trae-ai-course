## 一、项目概述

「外星人入侵」是一款基于 Pygame 的纵版射击游戏。玩家操控屏幕底部的飞船，左右移动并发射子弹，消灭从上方向下移近的外星舰队。

本章实现的核心能力：

| 模块 | 功能 |
|------|------|
| 舰队生成 | 根据屏幕尺寸自动计算行列，批量生成外星人 |
| 舰队移动 | 整体左右移动，碰边后下移并换向 |
| 子弹碰撞 | 子弹击中外星人后双方消失；清空后生成新舰队 |
| 失败判定 | 外星人撞飞船 / 抵达底部 → 损失一艘飞船；飞船耗尽 → 游戏结束 |

设计上贯穿两条原则：

- **用 `rect` 做渲染，用浮点数保存精确位置**，避免整数取整造成的漂移。
- **持续重构**：把复杂逻辑拆成小函数（计算数量、创建对象、检测碰撞），方便扩展。

## 四、settings.py — 游戏配置

集中存放所有可调参数，方便后续做「难度递增」「计分」等扩展。

```python
class Settings:
    """存储游戏所有设置的类。"""

    def __init__(self):
        # 屏幕设置
        self.screen_width = 1200
        self.screen_height = 800
        self.bg_color = (230, 230, 230)

        # 飞船设置
        self.ship_speed_factor = 1.5
        self.ship_limit = 3          # 初始拥有飞船数

        # 子弹设置
        self.bullet_speed_factor = 3
        self.bullet_width = 3
        self.bullet_height = 15
        self.bullet_color = (60, 60, 60)
        self.bullets_allowed = 3    # 同屏最多子弹数

        # 外星人设置
        self.alien_speed_factor = 1
        self.fleet_drop_speed = 10   # 碰边后下移距离
        self.fleet_direction = 1    # 1=向右，-1=向左
```

### 参数说明

| 参数 | 含义 | 调参建议 |
|------|------|----------|
| `ship_speed_factor` | 飞船每帧位移 | 越大操控越灵敏 |
| `ship_limit` | 初始生命数 | 新手可调大到 5 |
| `bullets_allowed` | 同屏子弹上限 | 限制输出节奏 |
| `fleet_drop_speed` | 舰队下移速度 | 越大压迫感越强 |
| `fleet_direction` | 方向标志 | 用 ±1 便于乘法换向 |

## 五、ship.py — 飞船类

```python
import pygame

class Ship:
    """管理飞船的类。"""

    def __init__(self, ai_settings, screen):
        self.screen = screen
        self.ai_settings = ai_settings

        # 加载飞船图像并获取外接矩形
        self.image = pygame.image.load('images/ship.bmp')
        self.rect = self.image.get_rect()
        self.screen_rect = screen.get_rect()

        # 每艘新飞船放在屏幕底部中央
        self.rect.centerx = self.screen_rect.centerx
        self.rect.bottom = self.screen_rect.bottom

        # 用浮点数保存精确位置
        self.center = float(self.rect.centerx)

        # 移动标志
        self.moving_right = False
        self.moving_left = False

    def update(self):
        """根据移动标志调整飞船位置，并限制在屏幕内。"""
        if self.moving_right and self.rect.right < self.screen_rect.right:
            self.center += self.ai_settings.ship_speed_factor
        if self.moving_left and self.rect.left > 0:
            self.center -= self.ai_settings.ship_speed_factor

        # 根据浮点数更新 rect（rect 只用于渲染）
        self.rect.centerx = self.center

    def blitme(self):
        """在指定位置绘制飞船。"""
        self.screen.blit(self.image, self.rect)

    def center_ship(self):
        """让飞船回到屏幕底部中央（被撞后重置用）。"""
        self.center = self.screen_rect.centerx
```

### 关键点

- `self.center` 是浮点数，`self.rect.centerx` 是整数；每帧用前者覆盖后者，避免累加漂移。
- `update()` 里同时判断边界，飞船不会飞出屏幕。
- `center_ship()` 不销毁飞船对象，只重置水平位置，响应速度快。

## 六、bullet.py — 子弹类

子弹继承自 `pygame.sprite.Sprite`，可以被 `Group` 批量管理。

```python
import pygame
from pygame.sprite import Sprite

class Bullet(Sprite):
    """管理飞船发射的子弹。"""

    def __init__(self, ai_settings, screen, ship):
        super().__init__()
        self.screen = screen

        # 在 (0,0) 创建子弹矩形，再设置正确位置
        self.rect = pygame.Rect(
            0, 0,
            ai_settings.bullet_width,
            ai_settings.bullet_height
        )
        self.rect.centerx = ship.rect.centerx
        self.rect.top = ship.rect.top

        # 用浮点数保存纵向位置
        self.y = float(self.rect.y)

        self.color = ai_settings.bullet_color
        self.speed_factor = ai_settings.bullet_speed_factor

    def update(self):
        """向上移动子弹。"""
        self.y -= self.speed_factor      # y 减小 = 向上
        self.rect.y = self.y

    def draw_bullet(self):
        """在屏幕上绘制子弹。"""
        pygame.draw.rect(self.screen, self.color, self.rect)
```

### 为什么用 `pygame.Rect` 而不是图片？

子弹是简单的矩形色块，直接用 `Rect` 绘制比加载图片更轻量，也便于调整大小。

## 七、alien.py — 外星人类

```python
import pygame
from pygame.sprite import Sprite

class Alien(Sprite):
    """表示单个外星人的类。"""

    def __init__(self, ai_settings, screen):
        super().__init__()
        self.screen = screen
        self.ai_settings = ai_settings

        # 加载外星人图像
        self.image = pygame.image.load('images/alien.bmp')
        self.rect = self.image.get_rect()

        # 初始位置：屏幕左上角附近（留一个身位边距）
        self.rect.x = self.rect.width
        self.rect.y = self.rect.height

        # 保存精确的横向位置
        self.x = float(self.rect.x)

    def check_edges(self):
        """如果外星人碰到屏幕左右边缘，返回 True。"""
        screen_rect = self.screen.get_rect()
        if self.rect.right >= screen_rect.right:
            return True
        elif self.rect.left <= 0:
            return True
        return False

    def update(self):
        """向右或向左移动外星人。"""
        self.x += (
            self.ai_settings.alien_speed_factor
            * self.ai_settings.fleet_direction
        )
        self.rect.x = self.x

    def blitme(self):
        """绘制外星人。"""
        self.screen.blit(self.image, self.rect)
```

### 关键点

- `check_edges()` 是舰队整体换向的判断依据。
- `update()` 用 `fleet_direction` 乘以速度，方向翻转时无需改代码，只需把 `direction` 取反。

## 八、game_stats.py — 游戏统计

```python
class GameStats:
    """跟踪游戏的统计信息。"""

    def __init__(self, ai_settings):
        self.ai_settings = ai_settings
        self.reset_stats()

        # 游戏刚启动时处于活动状态
        self.game_active = True

    def reset_stats(self):
        """初始化在游戏运行期间可能变化的统计信息。"""
        self.ships_left = self.ai_settings.ship_limit
```

### 为什么要拆出 `reset_stats()`？

因为开始新一局时需要重置剩余飞船数，但不需要重新创建 `GameStats` 对象。把「可变状态」集中在一个方法里，后续加 Play 按钮、最高分、关卡数时都复用它。

## 九、game_functions.py — 游戏主逻辑

这是最长的文件，集中了事件监听、子弹更新、舰队生成、碰撞检测等所有辅助函数。

```python
import sys
from time import sleep

import pygame

from bullet import Bullet
from alien import Alien


# ---------- 事件处理 ----------

def check_keydown_events(event, ai_settings, screen, ship, bullets):
    """响应按键按下。"""
    if event.key == pygame.K_RIGHT:
        ship.moving_right = True
    elif event.key == pygame.K_LEFT:
        ship.moving_left = True
    elif event.key == pygame.K_SPACE:
        fire_bullet(ai_settings, screen, ship, bullets)
    elif event.key == pygame.K_q:
        sys.exit()


def check_keyup_events(event, ship):
    """响应按键松开。"""
    if event.key == pygame.K_RIGHT:
        ship.moving_right = False
    elif event.key == pygame.K_LEFT:
        ship.moving_left = False


def check_events(ai_settings, screen, ship, bullets):
    """监听键盘和鼠标事件。"""
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            sys.exit()
        elif event.type == pygame.KEYDOWN:
            check_keydown_events(event, ai_settings, screen, ship, bullets)
        elif event.type == pygame.KEYUP:
            check_keyup_events(event, ship)


def fire_bullet(ai_settings, screen, ship, bullets):
    """若未达上限，就发射一颗子弹。"""
    if len(bullets) < ai_settings.bullets_allowed:
        new_bullet = Bullet(ai_settings, screen, ship)
        bullets.add(new_bullet)


# ---------- 屏幕绘制 ----------

def update_screen(ai_settings, screen, ship, aliens, bullets):
    """更新屏幕上的图像，并切换到新屏幕。"""
    screen.fill(ai_settings.bg_color)

    for bullet in bullets.sprites():
        bullet.draw_bullet()

    ship.blitme()
    aliens.draw(screen)

    pygame.display.flip()


# ---------- 子弹更新与碰撞 ----------

def update_bullets(ai_settings, screen, ship, aliens, bullets):
    """更新子弹位置，删除飞出屏幕的子弹，处理碰撞。"""
    bullets.update()

    # 删除已消失的子弹（遍历副本才能安全 remove）
    for bullet in bullets.copy():
        if bullet.rect.bottom <= 0:
            bullets.remove(bullet)

    check_bullet_alien_collisions(ai_settings, screen, ship, aliens, bullets)


def check_bullet_alien_collisions(ai_settings, screen, ship, aliens, bullets):
    """响应子弹与外星人的碰撞。"""
    # 两个 True 表示：碰撞后子弹和外星人都消失
    collisions = pygame.sprite.groupcollide(bullets, aliens, True, True)

    # 舰队清空 → 删光残留子弹，生成新舰队
    if len(aliens) == 0:
        bullets.empty()
        create_fleet(ai_settings, screen, ship, aliens)


# ---------- 舰队生成 ----------

def get_number_aliens_x(ai_settings, alien_width):
    """计算一行能放多少外星人。"""
    available_space_x = ai_settings.screen_width - 2 * alien_width
    number_aliens_x = int(available_space_x / (2 * alien_width))
    return number_aliens_x


def get_number_rows(ai_settings, ship_height, alien_height):
    """计算能放多少行外星人。"""
    available_space_y = (
        ai_settings.screen_height
        - (3 * alien_height)
        - ship_height
    )
    number_rows = int(available_space_y / (2 * alien_height))
    return number_rows


def create_alien(ai_settings, screen, aliens, alien_number, row_number):
    """创建一个外星人并放到指定位置。"""
    alien = Alien(ai_settings, screen)
    alien_width = alien.rect.width
    alien.x = alien_width + 2 * alien_width * alien_number
    alien.rect.x = alien.x
    alien.rect.y = alien.rect.height + 2 * alien.rect.height * row_number
    aliens.add(alien)


def create_fleet(ai_settings, screen, ship, aliens):
    """创建完整的外星舰队。"""
    alien = Alien(ai_settings, screen)
    number_aliens_x = get_number_aliens_x(ai_settings, alien.rect.width)
    number_rows = get_number_rows(
        ai_settings, ship.rect.height, alien.rect.height
    )

    for row_number in range(number_rows):
        for alien_number in range(number_aliens_x):
            create_alien(ai_settings, screen, aliens, alien_number, row_number)


# ---------- 舰队移动 ----------

def check_fleet_edges(ai_settings, aliens):
    """任意外星人碰边 → 整队下移并换向。"""
    for alien in aliens.sprites():
        if alien.check_edges():
            change_fleet_direction(ai_settings, aliens)
            break


def change_fleet_direction(ai_settings, aliens):
    """整队下移，并反转方向。"""
    for alien in aliens.sprites():
        alien.rect.y += ai_settings.fleet_drop_speed
    ai_settings.fleet_direction *= -1


# ---------- 失败判定 ----------

def ship_hit(ai_settings, stats, screen, ship, aliens, bullets):
    """响应飞船被外星人撞到。"""
    if stats.ships_left > 0:
        stats.ships_left -= 1

        # 清空外星人和子弹
        aliens.empty()
        bullets.empty()

        # 生成新舰队，飞船归位
        create_fleet(ai_settings, screen, ship, aliens)
        ship.center_ship()

        # 短暂暂停，让玩家看到发生了什么
        sleep(0.5)
    else:
        stats.game_active = False


def check_aliens_bottom(ai_settings, stats, screen, ship, aliens, bullets):
    """检查是否有外星人到达屏幕底部。"""
    screen_rect = screen.get_rect()
    for alien in aliens.sprites():
        if alien.rect.bottom >= screen_rect.bottom:
            ship_hit(ai_settings, stats, screen, ship, aliens, bullets)
            break


def update_aliens(ai_settings, stats, screen, ship, aliens, bullets):
    """更新所有外星人位置，并检测碰撞。"""
    check_fleet_edges(ai_settings, aliens)
    aliens.update()

    # 外星人和飞船碰撞
    if pygame.sprite.spritecollideany(ship, aliens):
        ship_hit(ai_settings, stats, screen, ship, aliens, bullets)

    # 外星人到达底部
    check_aliens_bottom(ai_settings, stats, screen, ship, aliens, bullets)
```

### 函数职责一览

| 函数 | 职责 |
|------|------|
| `check_events` | 事件总入口 |
| `fire_bullet` | 按上限发射子弹 |
| `update_screen` | 每帧重绘 |
| `update_bullets` | 子弹位置 + 碰撞 |
| `create_fleet` | 生成整队外星人 |
| `check_fleet_edges` | 碰边检测 |
| `change_fleet_direction` | 整队下移 + 换向 |
| `ship_hit` | 飞船被撞后的统一处理 |
| `check_aliens_bottom` | 抵底检测 |
| `update_aliens` | 外星人更新总入口 |

## 十、alien_invasion.py — 主程序

```python
import pygame

from settings import Settings
from game_stats import GameStats
from ship import Ship
from alien import Alien
import game_functions as gf


def run_game():
    # 初始化
    pygame.init()
    ai_settings = Settings()
    screen = pygame.display.set_mode(
        (ai_settings.screen_width, ai_settings.screen_height)
    )
    pygame.display.set_caption("Alien Invasion")

    # 游戏统计
    stats = GameStats(ai_settings)

    # 游戏对象
    ship = Ship(ai_settings, screen)
    bullets = pygame.sprite.Group()
    aliens = pygame.sprite.Group()

    gf.create_fleet(ai_settings, screen, ship, aliens)

    # 主循环
    while True:
        gf.check_events(ai_settings, screen, ship, bullets)

        if stats.game_active:
            ship.update()
            gf.update_bullets(ai_settings, screen, ship, aliens, bullets)
            gf.update_aliens(
                ai_settings, stats, screen, ship, aliens, bullets
            )

        gf.update_screen(ai_settings, screen, ship, aliens, bullets)


run_game()
```

### 主循环关键分支

```python
if stats.game_active:
    ship.update()
    gf.update_bullets(...)
    gf.update_aliens(...)
```

- **游戏进行中**：才更新飞船、子弹、外星人。
- **游戏结束后**：仍然监听事件（比如按 Q 退出）、仍然刷新屏幕，但不再推进游戏状态。

## 十一、核心概念速查

### 1. Sprite 与 Group

| 概念 | 说明 |
|------|------|
| `pygame.sprite.Sprite` | 游戏对象基类，子类化后可加入 Group |
| `pygame.sprite.Group()` | 精灵容器，支持批量 `update()` / `draw()` / `empty()` |

常用方法：

```python
aliens = pygame.sprite.Group()
aliens.add(alien)      # 加入
aliens.update()       # 批量调用每个精灵的 update
aliens.draw(screen)   # 批量绘制
aliens.empty()        # 清空
```

### 2. 两个碰撞函数

| 函数 | 用途 |
|------|------|
| `pygame.sprite.groupcollide(g1, g2, d1, d2)` | 两组精灵之间碰撞，返回字典 |
| `pygame.sprite.spritecollideany(sprite, group)` | 单个精灵 vs 一组精灵，命中返回对象，否则 None |

`groupcollide` 四个参数：

```python
pygame.sprite.groupcollide(bullets, aliens, True, True)
#                                  ↑        ↑
#                          碰撞后删子弹  碰撞后删外星人
```

把第三个参数改成 `False`，子弹就会穿透（用于测试）。

### 3. 浮点数位置模式

```python
self.x = float(...)   # 精确
self.rect.x = self.x  # 渲染用
```

每帧从浮点数同步到整数 `rect`，避免累加取整造成的位置漂移。

### 4. 标志变量模式

```python
self.game_active = True / False
```

用一个布尔标志控制游戏主循环是否推进，比多层嵌套 `if` 更清晰。后续可以扩展出 `paused`、`show_menu` 等标志。

## 十二、执行流程总图

### 启动 → 主循环

```
run_game()
   │
   ├── 初始化 pygame、设置、屏幕
   ├── 创建 stats、ship、bullets、aliens
   ├── create_fleet() 生成初始舰队
   │
   └── while True:
          │
          ├── check_events()        # 监听按键
          │
          ├── if game_active:
          │      ├── ship.update()
          │      ├── update_bullets()
          │      │     ├── bullets.update()
          │      │     ├── 删除飞出屏幕的子弹
          │      │     └── groupcollide() → 清空则重建舰队
          │      └── update_aliens()
          │            ├── check_fleet_edges()
          │            ├── aliens.update()
          │            ├── spritecollideany(ship, aliens) → ship_hit()
          │            └── check_aliens_bottom() → ship_hit()
          │
          └── update_screen()      # fill → draw bullets → blit ship → draw aliens → flip
```

### 飞船被撞后的流程

```
外星人撞飞船 / 抵达底部
        ↓
   ship_hit()
        ↓
 ships_left > 0 ?
   ├── 是 → ships_left -= 1
   │       → aliens.empty()
   │       → bullets.empty()
   │       → create_fleet()
   │       → ship.center_ship()
   │       → sleep(0.5)
   │
   └── 否 → game_active = False
              → 主循环停止更新，但仍监听事件
```

- 屏幕底部一个可左右移动的角色；

核心就是把本章的 `ships_left` 换成 `misses`，把 `ship_hit` 换成 `ball_missed`。

## 附录：常见报错排查

| 报错 | 原因 | 解决 |
|------|------|------|
| `pygame.error: Couldn't open images/ship.bmp` | 图片路径不对 | 确认 `images/` 与 `.py` 同级 |
| 飞船/外星人不移动 | `moving_right` 标志没置 True | 检查 KEYDOWN / KEYUP 是否配对 |
| 子弹只发一颗就没了 | `bullets_allowed` 或 `fire_bullet` 判断错 | 确认 `len(bullets) < ai_settings.bullets_allowed` |
| 舰队只生成一行 | `get_number_rows` 计算错误 | 检查 `available_space_y` 的减法 |
| 游戏结束后窗口卡住 | `game_active = False` 后没继续 `check_events` | 把事件监听放在 `if game_active` 外面 |
