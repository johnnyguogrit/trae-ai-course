## 模块 1：定时器 —— 让代码"过一会儿再做"（10 分钟）

### 知识点讲解

```javascript
setInterval(function () {
    console.log("每 1 秒喊我一次");
}, 1000);              // 1000 毫秒 = 1 秒

setTimeout(function () {
    console.log("3 秒后只喊我一次");
}, 3000);
```

- `setInterval`：每隔一段时间**反复**执行（倒计时、地鼠出现都靠它）。
- `setTimeout`：过一段时间后**只执行一次**（地鼠缩回洞里）。
- 停掉定时器：`clearInterval(定时器变量)`。

### 教师演示脚本

1. 输入注释 `// 每 1 秒在控制台打印一次当前秒数` → Tab 补全。
2. 演示一个 5 秒倒计时：变量从 5 开始，setInterval 每秒减 1，到 0 时 clearInterval 并打印"时间到"。

### 学生动手任务（5 分钟）

做一个 10 秒倒计时器显示在页面上，到 0 显示"时间到！"。

> **AI 提示词示例**：
>
> ```
> 用 JavaScript 写一个 10 秒倒计时：页面有个 id="time" 的元素显示剩余秒数，setInterval 每秒减 1 并更新显示，到 0 时用 clearInterval 停止并显示"时间到！"。加中文注释。
> ```

## 模块 2：随机数 —— 地鼠从哪个洞出来？（10 分钟）

### 知识点讲解

```javascript
Math.random()                    // 0 到 1 之间的小数，如 0.7431
Math.floor(Math.random() * 9)    // 0 到 8 的随机整数：随机选一个洞
```

- `Math.floor` 向下取整，`Math.random() * 9` 是 0~8.99，合起来就是 0~8。
- 配合数组：`holes[随机下标]` 就能随机抓一个洞元素。

### 教师演示脚本

1. 控制台里连续敲几次 `Math.floor(Math.random() * 9)`，让学生看到随机性。
2. 输入注释 `// 从 id 列表 holes 里随机取一个元素，给它加上 active 样式类` → Tab。

### 学生动手任务（5 分钟）

页面放 6 个不同颜色的方块，点一个按钮，随机让一个方块闪烁（加再移除一个 CSS 类）。

> **AI 提示词示例**：
>
> ```
> 页面有 6 个 class="box" 的方块。写 JS：点击按钮时，用 Math.random 随机选一个方块加上 highlight 类（变亮），1 秒后移除。加中文注释。
> ```

## 模块 3：项目实战 —— 打地鼠（30 分钟）

### 游戏规则

- 3×3 共 9 个洞，地鼠每 0.8 秒随机从一个洞冒出，停留 1 秒后缩回。
- 点中地鼠 +1 分；游戏总时长 30 秒，结束后显示总分和"重新开始"按钮。

### 教师演示脚本（15 分钟）—— 半 AI 生成 + 学生补全

1. 用 Builder 生成游戏骨架（提示词见下），但**故意删掉核心逻辑**：地鼠出现/计分的 JS 函数留空，留给学生补全。
2. 运行演示骨架：能看到 9 个洞和开始按钮，但地鼠不出现——"接下来靠你们了"。

> **AI 提示词示例**（Builder 模式，生成骨架用）：
>
> ```
> 帮我生成一个打地鼠网页游戏，三个文件 index.html / style.css / script.js：
> 1. 页面有 3×3 共 9 个圆洞（div），一个分数显示区，一个倒计时显示区，一个"开始游戏"按钮；
> 2. 地鼠用 emoji 🐹 表示，出现在洞里就显示 emoji，缩回就隐藏；
> 3. 点开始游戏后：倒计时 30 秒，每 800 毫秒随机让一个洞出现地鼠，地鼠停留 1000 毫秒后消失；
> 4. 点击出现中的地鼠得 1 分并立刻消失；
> 5. 时间到后弹出总分，并显示"重新开始"按钮；
> 6. 代码加详细中文注释。
> ```

### 学生动手任务（15 分钟）—— 读懂并补全核心逻辑

打开配套源码 `projects/whack_a_mole/script.js`，完成以下阅读任务（**先读懂，再动手改**）：

1. **找一找**：`showMole` 函数里哪一行决定地鼠停在哪个洞？哪一行让它消失？
2. **改一改**：把游戏时长从 30 秒改成 15 秒；把地鼠出现间隔从 800 毫秒改成 500 毫秒（难度上升）。
3. **加一加**：增加"连击提示"——连续点中 3 次时，分数区闪一下金色（不会就问 Chat，提示词见下）。

> **AI 提示词示例**（加功能时用）：
>
> ```
> 这是我的打地鼠 script.js（粘贴代码）。请帮我加"连击"功能：连续点中地鼠 3 次时，分数显示区背景闪金色 1 秒；点空或点错就清零连击数。只改必要的代码，说明改了哪几处。
> ```

## 常见问题与 AI 排错指南

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 地鼠不出现 | setInterval 没启动 / 选择器抓不到洞 | F12 看报错；检查 class 名拼写 |
| 地鼠出现后不消失 | setTimeout 里的代码没执行或写错 | 检查定时器内部代码和括号配对 |
| 点地鼠不加分 | 事件绑错元素，或点了但地鼠已消失 | 给点击事件里加 `console.log("点中了")` 验证 |
| 点"开始"多次后地鼠乱闪 | 重复点了开始，开了多个定时器 | 开始时先 clearInterval 旧定时器，并禁用开始按钮 |
| 倒计时变负数 | 到 0 时没 clearInterval | 检查 `if (time <= 0)` 的分支 |

排错提示词：

```
这是我的 script.js（粘贴），现在的问题是【描述现象】。请帮我定位到出问题的函数，解释原因，并给出修改后的代码片段。
```
