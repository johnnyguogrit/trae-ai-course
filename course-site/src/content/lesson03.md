## 模块 1：if 判断 —— 程序的"选择题"（10 分钟）

### 知识点讲解

```python
score = 85
if score >= 60:        # 如果分数大于等于 60
    print("及格啦！")   # 注意缩进 4 格
else:                  # 否则
    print("继续加油！")
```

- `if` 后面是**条件**，成立（True）就执行缩进的代码。
- 多分支用 `elif`：`if ... elif ... elif ... else ...`。
- 比较符号：`>` `<` `>=` `<=` `==`（等于，两个等号！） `!=`（不等于）。

### 教师演示脚本

1. 输入注释 `# 如果分数大于等于 90 打印优秀，大于等于 60 打印及格，否则打印加油` → Tab 补全整段。
2. 故意把 `==` 写成 `=`，运行演示报错，贴给 Chat 让 AI 解释。

### 学生动手任务（5 分钟）

写程序：用 input 问年龄，如果小于 12 打印"儿童票"，小于 18 打印"学生票"，否则打印"成人票"。

## 模块 2：for 循环与列表（10 分钟）

### 知识点讲解

- **列表**：一个能装很多值的盒子，用中括号：`fruits = ["苹果", "香蕉", "西瓜"]`。
- **for 循环**：把列表里的东西一个个拿出来干活：

```python
for fruit in fruits:      # 对列表里每个元素
    print(f"我喜欢吃{fruit}")  # 都执行一遍
```

- `range(5)` 会生成 0、1、2、3、4，常配合 for 用：`for i in range(5):`。

### 教师演示脚本

1. 输入注释 `# 定义一个列表存 4 个同学的名字` → Tab。
2. 输入注释 `# 用 for 循环逐个打印：欢迎 XXX 来到课堂` → Tab。
3. 演示 `for i in range(1, 6): print(i)`，打印 1~5。

### 学生动手任务（5 分钟）

做一个"班级点名器"：列表存 5 个名字，for 循环打印"X 号：名字"（提示：`for i, name in enumerate(列表)`，不会就问 AI）。

## 模块 3：while 循环与 random（10 分钟）

### 知识点讲解

- **while 循环**：条件成立就一直转，像"只要没吃饱就继续吃"：

```python
count = 0
while count < 3:        # 只要 count 小于 3
    print("再跑一次")
    count = count + 1   # 千万别忘这句，否则永远停不下来（死循环！）
```

- **random 模块**：`import random` 之后，`random.randint(1, 100)` 生成 1~100 的随机整数。
- 跳出循环用 `break`。

### 教师演示脚本

1. 输入注释 `# 导入 random 模块，生成 1 到 100 的随机整数存进 secret` → Tab。
2. 输入注释 `# while 循环：只要猜的数字不等于 secret 就一直让用户猜` → Tab。
3. 强调死循环风险：演示注释掉 `count = count + 1` 的后果（用 Ctrl+C 中断）。

### 学生动手任务（5 分钟）

写一个 while 循环：反复问用户"还要继续吗？(y/n)"，输入 n 时用 break 退出并打印"再见"。

## 常见报错与 AI 排错指南

| 报错/现象 | 大白话解释 | 修法 |
| --- | --- | --- |
| 程序卡住不结束 | 死循环：while 条件永远成立 | Ctrl+C 中断，检查循环里有没有让条件变化的语句 |
| `TypeError: '<' not supported between 'str' and 'int'` | 拿文字和数字比大小 | input 的结果忘了 `int()` 转换 |
| `IndentationError` | 循环/判断内部缩进不一致 | 统一用 4 个空格，别混 Tab 和空格 |
| 每次都猜中同一个数 | 把 `random.randint` 写进了循环外又覆盖了，或写错变量名 | 检查随机数是否只在开头生成一次 |

排错提示词模板：

```
这是我的代码和报错信息（粘贴）。我是初学者，请：1. 用大白话解释错误原因；2. 告诉我改哪几行；3. 给出改好的完整代码。
```
