# AI 协同编程课（基于字节跳动 Trae）

> 面向零基础学生的 AI 编程启蒙课：学会让 AI 帮你写代码，而不是自己死磕代码。

---

## 一、课程定位

这是一门 **"AI 时代的第一门编程课"**。传统编程课让学生先背语法再写代码，常常 3 节课就劝退一半人。本课程换一种思路：

- **先跑起来，再理解** —— 每个知识点都先让代码跑起来看到效果，再回头讲原理。
- **AI 是结对编程伙伴** —— 全程使用字节跳动的 AI IDE「Trae」，让学生掌握两项核心 AI 能力：
  1. **AI 代码补全**（Tab 补全 / Coding Copilot）：写注释，AI 自动续写代码，按 Tab 接受。
  2. **Vibe Coding**（氛围编程）：用自然语言描述需求，通过 Trae 的 **Chat / Builder 模式** 直接生成完整项目，再由学生迭代优化。
- **即学即练** —— 每个知识点拆成 5~15 分钟的小模块，讲完立刻动手，每节课都有一个能带回家的趣味作品。

教学模式参考吴恩达《AI Python for Beginners》：小步子、多练习、AI 全程陪跑。

## 二、适合人群

- **年龄**：12 岁以上（初中及以上），零基础完全 OK。
- **前置要求**：会打字、会用浏览器、会上网。不需要任何编程基础。
- **设备**：每人一台电脑（Windows / macOS 均可），能联网。

## 三、总课时

**16 课时 = 8 课 × 2 课时**（每课时 45 分钟，建议每次课中间休息 10 分钟）。

## 四、教学目标

### AI 能力目标（本课程的核心特色）

| 能力 | 具体表现 |
| --- | --- |
| AI 代码补全 | 能通过写注释引导 Trae 补全代码，熟练用 Tab 接受 / Esc 拒绝，能判断补全结果是否合理 |
| Vibe Coding | 能用清晰的自然语言描述需求，让 Trae Builder 生成完整项目并运行 |
| 提示词工程 | 掌握"三次提示法"：自己写提示词 → 对比 AI 输出 → 迭代优化提示词 |
| AI 排错 | 程序报错时，会把报错信息贴给 AI 并理解 AI 给的修复建议 |
| 代码阅读 | 能读懂 AI 生成的代码大意，知道"哪里改颜色、哪里改数字" |

### 编程语言目标

| 语言 | 掌握内容 |
| --- | --- |
| Python | 变量、字符串、数字、print/input、if/for/while、列表、字典、函数、random 模块 |
| HTML | 常用标签（h1/p/img/button/div/input）、结构语义、引入 CSS/JS |
| CSS | 颜色、字体、盒模型、居中布局、hover 效果 |
| JavaScript | 变量、函数、事件监听、DOM 操作、定时器 |

## 六、Trae 环境准备

### 1. 下载安装

1. 打开浏览器，访问 Trae 官网：https://www.trae.ai （或国内版 https://www.trae.com.cn ）
2. 点击「下载」，选择 Windows 或 macOS 版本。
3. 双击安装包，一路「下一步」完成安装（和装普通软件一样）。

### 2. 登录

- 首次打开 Trae 会要求登录，支持 **手机号 / 邮箱 / GitHub 账号** 登录。
- 登录后即可免费使用 AI 补全和 Chat 功能（Builder 模式可能需要排队或开通权限，以官网说明为准）。

### 3. 认识界面（第一次上课必讲）

| 区域 | 名称 | 用途 |
| --- | --- | --- |
| 左侧 | 文件资源管理器 | 看项目里有哪些文件 |
| 中间 | 代码编辑区 | 写代码的地方，**Tab 补全**就在这里发生 |
| 右侧 | Chat 面板 | 用自然语言和 AI 对话，问问题、让它改代码 |
| 右上角 | **Builder 模式** | 一句话生成整个项目，Vibe Coding 的主战场 |
| 底部 | 终端（Terminal） | 运行 Python 程序：`python 文件名.py` |

### 4. 快速自检（上课前老师带学生做一遍）

1. 新建文件 `test.py`，输入 `# 打印你好` 回车，看 AI 是否给出灰色补全 → 按 **Tab** 接受。
2. 打开右侧 Chat，输入「用一句话解释什么是变量」，确认能收到回复。
3. 打开 Builder，输入「帮我生成一个显示 Hello World 的网页」，确认能生成文件。

## 七、课程特色教学法

### 1. 小步子教学

每个知识点拆成 5~15 分钟的小模块：讲解 3 分钟 → 老师演示 3 分钟 → 学生动手 5 分钟。**绝不允许连续讲 20 分钟不让学生碰键盘。**

### 2. 即学即练

每节课都有明确的"产出物"，学生下课时手里一定有能运行、能展示给家长看的作品。

### 3. 三次提示法（提示词训练核心方法）

每次用 AI 生成代码时，要求学生走三步：

1. **第一次**：学生**先自己写提示词**（不抄袭、不看示例），发给 AI。
2. **第二次**：**对比 AI 输出**和自己的预期，哪里不对？哪里少了？
3. **第三次**：**迭代优化提示词**，把不满意的地方说清楚，重新生成。

> 口诀：**"先自己想，再看 AI 写，最后挑毛病。"**

### 4. 先跑起来再理解

遇到新概念，第一步永远是"让它跑起来"，看到效果后再回头讲原理。例如先让网页变色，再讲什么是 CSS。

### 5. AI 排错三步走

报错不是失败，是和 AI 对话的机会：

1. 复制完整报错信息；
2. 贴进 Trae Chat，加一句「我是初学者，请用大白话解释这个错误并告诉我怎么改」；
3. 按 AI 的建议改，改完再运行。
