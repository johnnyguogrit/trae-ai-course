## 模块 1：HTML —— 网页的骨架（10 分钟）

### 知识点讲解

```html
<h1>我是大标题</h1>
<p>我是一段话</p>
<img src="cat.jpg" alt="一只猫">
<a href="https://www.baidu.com">点我去百度</a>
```

- 标签像"括号"：`<p>` 开始、`</p>` 结束，中间是内容。
- 标签可以带**属性**：`src`（图片地址）、`href`（链接地址）。
- 所有内容包在 `<html><body> ... </body></html>` 里。

### 教师演示脚本

1. 新建 `demo.html`，输入注释 `<!-- 一个标题、一段自我介绍、一张网络图片 -->` → 看 AI 补全 → Tab。
2. 保存后右键 → 用浏览器打开，展示效果。

### 学生动手任务（5 分钟）

新建 `me.html`，写出：一个大标题（你的名字）、两段介绍、一张图片（可用 `https://api.dicebear.com/9.x/adventurer/svg?seed=你的名字`）。浏览器打开检查。

> **AI 提示词示例**：
>
> ```
> 生成一个简单的 HTML 文件：一个 h1 标题写我的名字，两段 p 自我介绍，一张 img 网络图片。加 HTML 注释说明每个标签的作用。
> ```

## 模块 2：CSS —— 给骨架穿上皮肤（15 分钟）

### 知识点讲解

```css
h1 {
    color: #e74c3c;        /* 文字颜色（十六进制色值） */
    font-size: 40px;       /* 字号 */
    text-align: center;    /* 居中 */
}
```

- 三种用法：写在标签里（`style="..."`）、写在 `<style>` 标签里、写在独立 `.css` 文件里（**推荐**，用 `<link>` 引入）。
- 选择器：`h1` 选中所有 h1；`.box` 选中 class="box" 的元素。
- 常用美化：`background` 背景、`border-radius` 圆角、`box-shadow` 阴影、`padding` 内边距。

### 教师演示脚本

1. 给刚才的 demo 加 `<style>`：改标题颜色、给图片加圆角和阴影。
2. 演示 **hover** 效果：`img:hover { transform: scale(1.1); }`——鼠标悬停图片放大。
3. 让学生观察：**改 CSS 不用动 HTML**，皮肤和骨架分离。

### 学生动手任务（8 分钟）

给自己的页面加样式：标题换颜色、背景换个浅色、图片变成圆形（`border-radius: 50%`）。

> **AI 提示词示例**：
>
> ```
> 给我的 HTML 页面加 CSS 样式：标题红色居中，页面背景浅蓝色，图片变成圆形并带阴影，鼠标悬停图片时放大 10%。把 CSS 写在 style 标签里并加注释。
> ```

## 模块 3：项目实战 —— 我的个人主页（25 分钟）

### 教师演示脚本

1. 打开 Builder，发送下方提示词生成主页骨架。
2. 用浏览器打开生成的页面，点评结构：导航区、自我介绍区、爱好列表、联系方式。
3. 打开配套模板 `projects/profile_page/index.html`，指出里面的 `<!-- 【改这里】 -->` 占位注释。

> **AI 提示词示例**（Builder 模式）：
>
> ```
> 帮我生成一个个人主页，包含 index.html 和 style.css 两个文件，要求：
> 1. 顶部是导航栏，显示我的名字；
> 2. 第一屏：圆形头像、名字大标题、一句座右铭，背景是渐变色；
> 3. "关于我"区域：三段自我介绍；
> 4. "我的爱好"区域：用无序列表展示 4 个爱好，每项有图标 emoji；
> 5. 底部：版权信息；
> 6. 整体配色清新，所有内容居中，加中文注释方便我学习。
> ```

### 学生动手任务（18 分钟）

1. 用 Builder 生成自己的主页（提示词按"三次提示法"先自己写）。
2. 打开生成的代码，**手动改 3 处**：名字、座右铭、至少一个颜色值（找到 `#xxxxxx` 改掉它）。
3. 加一个新板块：「我的日程表」（用列表或表格），提示词参考：

```
在"我的爱好"区域下面加一个"我的一天"区域，用表格展示我周末的时间安排（时间/事项两列，至少 4 行），样式和整页协调。
```

## 常见问题与 AI 排错指南

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 样式完全没生效 | `<link href="style.css">` 路径或文件名不对 | 检查 css 文件名拼写、是否在同一文件夹 |
| 图片裂了（小图标） | 图片地址错了 | 浏览器单独打开图片地址验证；检查 src 拼写 |
| 改了 CSS 没变化 | 浏览器缓存 | 强制刷新：Ctrl + F5 |
| 中文乱码 | 文件没声明 UTF-8 | 确认 `<head>` 里有 `<meta charset="UTF-8">` |

排错提示词：

```
这是我的 HTML 和 CSS 代码（粘贴），问题是：【描述现象】。请指出哪一行有问题并给出修改后的代码，用大白话解释原因。
```
