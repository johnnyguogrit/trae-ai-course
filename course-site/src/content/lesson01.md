# 第 1 课：你好，AI 编程伙伴

> 产出项目：**Hello World 个人名片页**（用 Trae Builder 一键生成的第一个网页）

---

## 本课目标

- 认识 Trae 界面：编辑区、Chat 面板、Builder 模式、终端。
- 完成第一次 **AI 代码补全**（Tab 补全）体验。
- 理解 **Vibe Coding** 的概念：用自然语言"说"出一个程序。
- 用 Builder 模式生成人生第一个网页，并在浏览器里打开它。

## 课前准备

- [ ] 每台电脑装好 Trae 并完成登录（参考 README 第六节）。
- [ ] 老师提前验证：Tab 补全可用、Chat 能回复、Builder 能生成文件。
- [ ] 新建一个空文件夹作为工作区，例如 `D:\mycode`，用 Trae 打开它。

## 模块 1：什么是编程？什么是 AI 编程伙伴？（10 分钟）

### 知识点讲解

- **编程**就是给计算机写"菜谱"：一步一步告诉它做什么。
- 以前写菜谱要自己背下所有"调料名称"（语法）；现在有 AI 伙伴，你说"我想做番茄炒蛋"，它帮你把菜谱写出来。
- Trae 里有两个 AI 帮手：
  - **补全（Tab）**：你写半句，它猜后半句。
  - **Chat / Builder**：你用中文提需求，它直接写完整代码。

### 教师演示脚本

1. 打开 Trae，指认界面四个区域（文件区 / 编辑区 / Chat / 终端）。
2. 新建文件 `hello.py`，输入一行注释 `# 打印一句你好，世界`，按回车。
3. 停住 2 秒，让学生看到 AI 给出的**灰色补全文字**，按 **Tab** 接受。
4. 打开底部终端，运行 `python hello.py`，看到输出。

### 学生动手任务（5 分钟）

1. 新建 `hello.py`。
2. 输入注释 `# 打印三句自我介绍` 后回车，等待补全，按 Tab 接受。
3. 在终端运行 `python hello.py`。

> **AI 提示词示例**（如果补全没出现，打开右侧 Chat 直接问）：
>
> ```
> 我是 Python 初学者，请帮我写一个 hello.py，打印三句自我介绍，每句一行，代码里加上中文注释。
> ```

## 模块 2：代码补全进阶体验（10 分钟）

### 知识点讲解

- AI 补全看的是**上下文**：你的文件名、注释、已经写的代码，都是它的"线索"。
- 注释写得越清楚，补全越准。这就是"用注释指挥 AI"。
- 补全不是圣旨：**Tab 接受，Esc 拒绝**，觉得不对就拒绝自己写。

### 教师演示脚本

1. 在 `hello.py` 里继续输入 `# 定义一个变量存我的名字` → 看补全 → Tab。
2. 输入 `# 打印 "我的名字是" 加上这个变量` → 看补全 → Tab。
3. 故意演示一次"补全错了"的情况，按 Esc 拒绝，自己改。

### 学生动手任务（5 分钟）

让 AI 补全完成下面三行注释对应的代码：

```python
# 定义一个变量 age，保存你的年龄
# 定义一个变量 hobby，保存你的爱好
# 打印一句话：我今年 X 岁，我喜欢 Y（把变量拼进句子里）
```

> **AI 提示词示例**（Chat 里用）：
>
> ```
> 请用 Python 的 f-string 方式，把变量 age 和 hobby 拼进一句打印语句里，给我一个初中生能看懂的例子。
> ```

## 模块 3：Vibe Coding 是什么？（10 分钟）

### 知识点讲解

- **Vibe Coding（氛围编程）**：不管语法细节，用大白话描述"我想要什么"，让 AI 生成整个项目，你再提意见让它改。
- 流程口诀：**说需求 → AI 生成 → 跑起来看 → 挑毛病 → 再改**。
- 你以后是"产品经理 + 验收员"，AI 是"程序员"。

### 教师演示脚本

1. 打开 Trae 的 **Builder 模式**。
2. 输入提示词（见下方示例），让学生观察 Builder 自动创建文件、写代码的全过程。
3. 生成完后，找到生成的 `index.html`，右键 → 用浏览器打开，展示效果。

> **AI 提示词示例**（Builder 模式，直接复制可用）：
>
> ```
> 帮我生成一个个人名片网页，单个 index.html 文件（CSS 写在 style 标签里）。要求：
> 1. 页面正中间显示名字"小明"和一句座右铭"代码改变世界"；
> 2. 背景是渐变色（蓝色到紫色）；
> 3. 名字用白色大字，有圆角卡片和阴影；
> 4. 所有文字居中。
> ```

### 学生动手任务（10 分钟）

用 **三次提示法** 生成你自己的名片页：

1. **第一次**：不看示例，自己用中文写一段需求发给 Builder（至少说清楚：名字、一句话介绍、想要什么颜色）。
2. **第二次**：打开生成的网页，记下 2 个不满意的地方。
3. **第三次**：把不满意的地方写成新的提示词（例如「把背景改成橙色渐变」「名字下面加一行我的爱好：篮球」），让 Builder 继续改。

## 课堂练习（10 分钟）

在名片页上追加功能，二选一：

- A. 加一张图片（可以是网络图片链接）；

```
在我的名片页名字下面加一张圆形头像图片，图片来自 https://api.dicebear.com/9.x/adventurer/svg?seed=Felix ，宽 120 像素。
```

## 常见报错与 AI 排错指南

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 终端里 `python` 不是命令 | Python 没装或没配置 | 请老师协助安装 Python，或先只玩网页部分 |
| 补全不出现 | 网络问题 / 没登录 | 检查登录状态；或改用 Chat 提问 |
| 浏览器打开是代码而不是页面 | 文件后缀不是 `.html` | 确认文件名以 `.html` 结尾 |
| 网页样式没生效 | CSS 写错位置 | 把报错或截图发给 Chat：「这是我的代码，样式为什么不生效？请用大白话告诉我」 |

**AI 排错三步走**：① 复制完整报错/截图描述现象 → ② 贴给 Chat 并说明"我是初学者" → ③ 按建议改，改完再运行。
