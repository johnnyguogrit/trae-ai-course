## 模块 1：变量与字符串（10 分钟）

### 知识点讲解

- **变量**就是一个贴了标签的盒子：`name = "小明"` 把"小明"放进叫 name 的盒子。
- **字符串**就是文字，用引号包住：`"你好"`。
- 字符串可以拼接：`"你好" + name`，也可以用 **f-string** 拼得更漂亮：`f"你好，{name}"`。

### 教师演示脚本

1. 新建 `demo1.py`，输入注释 `# 定义变量 name 保存名字` → Tab 接受补全。
2. 输入注释 `# 用 f-string 打印一句欢迎语` → Tab。
3. 终端运行，展示输出。

### 学生动手任务（5 分钟）

```python
# 定义变量 school 保存你的学校名
# 定义变量 grade 保存你的年级
# 用 f-string 打印：我在 XX 学校读 X 年级
```

逐行写注释，每行注释后面让 AI 补全代码，再运行。

> **AI 提示词示例**（Chat 里用）：
>
> ```
> 请用初中生能看懂的话解释 Python 的变量和字符串，并给一个 f-string 拼接的例子。
> ```

## 模块 2：数字与 input（10 分钟）

### 知识点讲解

- **数字**不用引号：`age = 13`，可以做加减乘除。
- **input()** 让程序停下来等你打字，打的内容会作为**字符串**返回。
- 重要坑：`input()` 拿到的是文字！想做数学计算要用 `int()` 转换：`age = int(input("你几岁？"))`。

### 教师演示脚本

1. 输入注释 `# 问用户几岁，把回答存进变量` → Tab，得到 `input` 代码。
2. 输入注释 `# 计算十年后几岁并打印` → 先故意不转 int，**演示报错**（字符串不能加数字）。
3. 把报错贴进 Chat，让 AI 解释，再改成 `int(input(...))` 修复。

### 学生动手任务（5 分钟）

写一个小程序：问用户出生年份，计算并打印他/她今年几岁（年份可用 2025 或当前年）。

> **AI 提示词示例**：
>
> ```
> 写一个 Python 小程序：用 input 问用户出生年份，用 int 转换后计算今年（2025年）几岁并打印，每行加中文注释。
> ```

## 模块 3：用补全写第一个函数（10 分钟）

### 知识点讲解

- **函数**是打包好的一段代码，起个名字就能反复用：

```python
def greet(name):        # def = 定义一个函数，名字叫 greet
    print(f"你好，{name}")  # 函数里面要做的事（注意缩进 4 格）

greet("小明")            # 调用函数：喊出它的名字就执行
```

- 写函数时先写注释描述功能，AI 补全往往能把整个函数补出来。

### 教师演示脚本

1. 输入 `# 定义一个函数，接收名字参数，打印个性化的早安问候` → 回车。
2. 观察 AI 是否补全整个函数，Tab 接受。
3. 再输入 `# 调用这个函数三次，传入不同名字` → Tab。

### 学生动手任务（5 分钟）

让 AI 帮你补全一个函数 `def add(a, b):`，返回两个数之和，然后打印 `add(3, 5)` 的结果。

> **AI 提示词示例**：
>
> ```
> 帮我写一个 Python 函数 add，接收两个数字返回它们的和，再写两行代码调用它并打印结果，加中文注释。
> ```

## 模块 4：项目实战 —— AI 聊天机器人（20 分钟）

### 知识点讲解

聊天机器人原理超简单：**你说一句话 → 程序检查这句话里有没有关键词 → 回一句对应的话**。这背后用到了字符串的 `in` 判断（第 3 课会细讲 if，今天先让 AI 帮我们写）。

### 教师演示脚本

1. 打开 `projects/chatbot/chatbot.py`，运行给学生看效果。
2. 带着学生读代码：哪里是输入、哪里是判断、哪里是回复。
3. 现场给机器人加一条新规则（比如用户说"考试"时回复"加油，你可以的！"）。

### 学生动手任务（15 分钟）

1. 运行配套源码 `chatbot.py`，和机器人聊 3 轮。
2. 用 Tab 补全或 Chat，给机器人**新增 2 条你自己的规则**（例如提到"游戏"、"作业"时的回复）。
3. 挑战：给机器人加开场白，先问用户名字，之后回复里都带上名字。

> **AI 提示词示例**（强烈推荐学生按"三次提示法"先自己写）：
>
> ```
> 请帮我写一个 Python 终端聊天机器人 chatbot.py：
> 1. 先打印欢迎语并用 input 问用户名字；
> 2. 然后进入循环，反复用 input 接收用户说的话；
> 3. 如果话里包含"你好"就回复问好，包含"名字"就介绍自己，包含"再见"就道别并结束程序，其他情况回复"我不太明白"；
> 4. 每行代码加中文注释。
> ```

## 常见报错与 AI 排错指南

| 报错 | 大白话解释 | 修法 |
| --- | --- | --- |
| `SyntaxError: invalid syntax` | 句子写错了，多半是漏了引号/冒号/括号 | 检查出错那一行的标点；贴给 Chat 问 |
| `NameError: name 'xxx' is not defined` | 用了一个没定义过的变量 | 检查变量名拼写，大小写要一致 |
| `ValueError: invalid literal for int()` | int() 里塞了不是数字的文字 | 确认输入的是数字，或去掉 int() |
| `IndentationError` | 缩进错了，Python 用空格表达"属于谁" | 函数/循环内部统一缩进 4 个空格 |

排错口诀：**看最后一行**（错误类型）→ **看行号**（去哪行）→ **贴给 AI**（让它翻译）。
