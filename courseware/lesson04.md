## 模块 1：函数 —— 代码的"打包复用"（10 分钟）

### 知识点讲解

```python
def add(a, b):      # a、b 是参数：递给函数的原料
    result = a + b
    return result   # return：把结果送出来

total = add(3, 5)   # 调用：送进 3 和 5，接住返回的 8
print(total)
```

- 为什么要函数？**一段代码写一次，到处用**；改的时候只改一处。
- 好函数的标准：名字说清干什么、只干一件事。

### 教师演示脚本

1. 输入注释 `# 定义一个函数，接收半径，返回圆的面积（圆周率取 3.14159）` → Tab 补全整个函数。
2. 输入注释 `# 调用函数计算半径 5 的圆面积并打印` → Tab。

### 学生动手任务（5 分钟）

让 AI 补全一个函数 `def is_even(n):`，判断 n 是不是偶数，返回 True 或 False；然后打印 1~10 里所有偶数。

> **AI 提示词示例**：
>
> ```
> 写一个 Python 函数 is_even(n)，判断整数 n 是否为偶数并返回 True/False；再用 for 循环打印 1~10 中所有偶数。加中文注释。
> ```

## 模块 2：字典 —— 配对的盒子（10 分钟）

### 知识点讲解

```python
words = {
    "apple": "苹果",      # 键 "apple" → 值 "苹果"
    "banana": "香蕉",
}
print(words["apple"])       # 按键取值：打印 苹果
words["cat"] = "猫"         # 新增一对
for en, zh in words.items():  # 遍历所有配对
    print(en, zh)
```

- 字典 = 查表：给一个英文单词，立刻查到中文。
- 常用操作：`字典[键]` 取值、`字典[键] = 值` 写入、`len(字典)` 数有多少对。

### 教师演示脚本

1. 输入注释 `# 定义字典存 5 个英语单词和中文意思` → Tab。
2. 输入注释 `# 让用户输入一个英语单词，查字典打印中文，查不到就提示` → Tab（顺带复习 if）。

### 学生动手任务（5 分钟）

做一个"迷你词典"：内置 5 个单词，用户输入英文查中文，输入 q 退出（while 循环 + 字典）。

> **AI 提示词示例**：
>
> ```
> 写一个 Python 迷你词典：内置 5 个初中英语单词的字典，while 循环让用户输入英文单词查中文意思，查不到提示"词典里没有"，输入 q 退出。加中文注释。
> ```

## 模块 3：Vibe Coding 初体验 —— 让 Builder 生成整个项目（25 分钟）

### 知识点讲解

前面我们用 Chat 和补全写"片段代码"；今天升级：用 **Builder 模式** 一句话生成**整个能运行的项目**。关键是把需求说"完整"：要什么功能、什么规则、数据是什么。

### 教师演示脚本

1. 打开 Builder 模式，完整念一遍需求（见下方提示词），发送。
2. 让 Builder 生成完后，在终端运行 `python word_match.py`，当场玩一轮。
3. 演示迭代：发第二条提示词「答对时加上鼓励的随机表情」让 Builder 改代码，再运行看变化。

> **AI 提示词示例**（Builder 模式，直接复制可用）：
>
> ```
> 帮我写一个 Python 终端背单词游戏"单词消消乐"，文件名 word_match.py，要求：
> 1. 内置 20 个初中英语单词及其中文意思（用字典存，比如 "apple": "苹果"）；
> 2. 每轮随机抽出 6 个单词，屏幕上先打乱顺序列出 6 个英文（编号 A-F），再打乱顺序列出对应的 6 个中文（编号 1-6）；
> 3. 玩家输入配对，格式如 "A3"（英文编号+中文编号），配对正确则消除这一对并加 10 分，错误扣 5 分并提示正确答案；
> 4. 一轮全部配对完成后显示本轮得分，问玩家是否再来一轮；
> 5. 代码加详细中文注释，适合初学者阅读。
> ```

### 学生动手任务（15 分钟）—— 三次提示法实战

1. **第一次**：不看上面示例，自己用中文向 Builder 描述这个单词配对游戏（至少包含：多少单词、怎么玩、怎么计分）。生成后运行。
2. **第二次**：玩一遍，记下 2 个想改进的点（例如：想显示剩余几对、想换一批单词、想要倒计时）。
3. **第三次**：把改进点写成清晰提示词让 Builder 改，改完再运行验证。

## 常见报错与 AI 排错指南

| 报错 | 大白话解释 | 修法 |
| --- | --- | --- |
| `KeyError: 'apple'` | 字典里没这个键就硬取 | 用 `字典.get(键)` 或先 `if 键 in 字典` 判断 |
| `TypeError: function takes 1 argument but 2 given` | 函数要的参数个数和你给的不一样 | 对照函数定义检查参数个数 |
| 返回值是 `None` | 函数忘了写 `return` | 检查函数最后一行有没有 return |
| Builder 生成的代码运行报错 | AI 也会写错 | 把报错原样贴回 Builder/Chat：「运行报这个错，请修复」 |

**给初学者的提醒**：AI 生成 ≠ 一定正确。Vibe Coding 的核心能力不是"会提要求"，而是"**会验证、会挑毛病、会要求修改**"。
