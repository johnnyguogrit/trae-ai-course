# AI 协同游戏设计 · 外星人入侵代码包

面向 12 岁以上零基础学生。8 个步骤都可 **独立运行**，不需要图片、声音或网络素材；飞船、外星人和子弹全部由 Pygame 几何图形绘制。

## 1. 安装与运行

需要 Python 3.10+。在本目录打开终端：

```bash
python -m pip install -r requirements.txt
```

运行任一步骤（以第 1 步为例）：

```bash
cd steps/step01
python main.py
```

运行模块化完整版：

```bash
cd final
python alien_invasion.py
```

若系统使用 `python3` 或 `py`，请替换上述 `python`。Pygame 游戏需在本地 Trae 终端运行，课程网页只提供学习指导和进度记录，不会直接运行游戏。

## 2. 操作键

| 按键 | 功能 |
| --- | --- |
| `←` / `→` | 移动飞船（第 2 步起） |
| `空格` | 发射子弹（第 3 步起） |
| `Enter` | 游戏结束后重新开始（第 7 步起） |
| `Q` / `Esc` / 窗口 `×` | 退出游戏 |

## 3. 8 步导览

| 步骤 | 主题 | 新增功能 | 学生修改重点 |
| --- | --- | --- | --- |
| `steps/step01/main.py` | 变量、while、事件 | 窗口与主循环 | 尺寸、背景色、标题 |
| `steps/step02/main.py` | 类、对象、布尔值、if | 飞船移动与边界 | 速度、颜色、安全边距 |
| `steps/step03/main.py` | 函数、列表、for | 发射与删除子弹 | 颜色、速度、同屏上限 |
| `steps/step04/main.py` | 嵌套循环、坐标计算 | 生成外星舰队 | 行数、列数、间距 |
| `steps/step05/main.py` | 方向参数、统一更新 | 移动、碰边下移换向 | 下移距离、初始方向、速度 |
| `steps/step06/main.py` | 碰撞、遍历删除 | 命中计分、舰队重建 | 命中分值、颜色效果 |
| `steps/step07/main.py` | 状态与重置 | 生命、结束、Enter 重开 | 生命数、重置规则 |
| `steps/step08/main.py` | 综合与个性化 | 分数、最高分、关卡加速 | 自选一种改造并验收 |

每一步的常量附近都有「学生修改区」。建议先运行原版，再一次改一个值。某一步失败时可直接打开下一步，不依赖前一步文件。

## 4. final 模块地图

```text
final/
├── alien_invasion.py   # 主入口与主循环
├── settings.py         # 静态参数与动态难度
├── ship.py             # 飞船类
├── bullet.py           # 子弹精灵
├── alien.py            # 外星人精灵
├── game_stats.py       # 生命、分数、最高分、关卡、活动状态
├── scoreboard.py       # HUD 与结束提示
└── game_functions.py   # 事件、更新、碰撞、生成、重置、绘制
```

保留参考项目的两条原则：用浮点变量保存精确位置、用 `rect` 绘制与碰撞；持续把复杂职责拆成小函数和清晰模块。

## 5. 教师使用建议

- 每步按「预测 → 手改 → 运行 → 解释 → 勾选」推进，不直接展示最终答案。
- IDE 模式用于逐行理解与小步修改；SOLO 模式用于完整需求、自动执行与验收对照。
- 学生必须完成每步修改任务，并填写 `student_worksheet.md`。
- 验收至少覆盖边界、连续射击、碰撞、失败/重开和旧功能回归。
- 讲义位于课程目录 `courseware/ai_game_design.md`，网页工作台为 `/game-lab`。

## 6. 可选自动验证

安装依赖后，在本目录执行：

```bash
python tools/smoke_test.py
```

脚本会使用 Pygame dummy 视频驱动，对第 1 步、第 8 步和模块化完整版做启动与自动退出冒烟测试；超时或异常会返回非零状态。
